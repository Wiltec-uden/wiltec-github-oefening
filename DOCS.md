belangrijkste handelingen te oefenen: clonen, branches maken, commits,

## Begrippen

- Clone: een kopie van een online repository naar je eigen computer halen.
- Branch: een aparte lijn om aan wijzigingen te werken zonder de hoofdversie te raken.
- Commit: een set wijzigingen vastleggen met een korte beschrijving.
- Push: je lokale commits naar de online repository sturen.
- Pull request: een voorstel om je branch samen te voegen, zodat anderen het kunnen bekijken.
- Merge: het goedgekeurde voorstel samenvoegen met de hoofdversie.
